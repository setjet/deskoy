  # Deskoy

  A Windows privacy cover for sensitive moments.

  [Website](https://www.deskoy.com) · [Download](https://www.deskoy.com/download) · [Docs](https://www.deskoy.com/docs) · [Support](https://www.deskoy.com/docs/support)
</div>

Deskoy lets you quickly cover your screen with a work surface using a hotkey or the system tray. This repository is the public home for **release downloads, update files, documentation, and issue reports**. The current application source is maintained privately.

## Download

Get the latest installer from [deskoy.com/download](https://www.deskoy.com/download) or [GitHub Releases](https://github.com/setjet/deskoy/releases). Verify that you are downloading from an official Deskoy link.

The current public Release is v1.3.0. Release availability may change independently of this documentation. Signed update assets are published under Releases for the in-app updater.

## Source availability

Earlier Deskoy source remains visible in this repository's public Git history under the [Deskoy Source-Available License](LICENSE). The current app, including Pro and licensing implementation, is not published here. This is a releases and support repository; it is not a buildable source checkout for current Deskoy versions.

Deskoy is a privacy convenience tool. It is not antivirus or a security boundary.
