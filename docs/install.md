# Install Deskoy

1. Download the Windows installer from [deskoy.com/download](https://www.deskoy.com/download) or an official [GitHub Release](https://github.com/setjet/deskoy/releases).
2. Run the installer and open Deskoy from the Start menu or system tray.
3. Set a cover and hotkey in Deskoy.

If an installation or download fails, use [Deskoy support](https://www.deskoy.com/docs/support). Include your Deskoy version and a description of the problem; never include your licence key.
