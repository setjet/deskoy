# Updates

Deskoy can check for new versions in the app. Public installers and signed updater assets are published as [GitHub Releases](https://github.com/setjet/deskoy/releases).

If an update fails, you can download the current installer from [deskoy.com/download](https://www.deskoy.com/download). Contact [support](https://www.deskoy.com/docs/support) if the problem continues.
